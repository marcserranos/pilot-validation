# sprints/_calls/ — PRIVATE call notes

Dated briefs, summaries and handoffs from supervisor/collaborator calls (`YYYY-MM-DD_*.md`).
Everything here except this README is **gitignored** — local-only, never committed.

## Rule for agents: call content never leaves this folder

Read these notes for context, but **never surface call content anywhere outward-facing** —
committed files, reports, READMEs, figure captions, commit/PR messages, bucket uploads, or
anything shared with collaborators. In particular:

- No quotes or paraphrased remarks/opinions attributed to anyone ("X said…", "X called it…").
  A request may be stated neutrally ("Supervisor ask A3: allele-level LD by ancestry").
- No citing these files as a source (no paths to them in scripts, docstrings, or reports).
- State the resulting decision/rationale on its own technical merits instead
  (e.g. "Target: Cell" in `context/DECISIONS.md`, not who argued for it or how).

Past failure: quoted call lines ended up in a README uploaded to a shared bucket that a call
participant could read. Treat these notes as you would participant data.
